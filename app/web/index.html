不会写 JSON？让 AI 替你转

提示词里已经填好了你当前的学期信息（名称、第 1 周周一、总周数）， 所以 AI 不会在这些地方猜错 —— 这些值错了，整张表的时间会全部错位。

用法：复制提示词 → 贴给豆包 / DeepSeek / Kimi / ChatGPT → 再把课表截图或文件一起发过去 → 它吐出的 JSON 存成 .json 文件 → 用上面的「选择文件导入」。
