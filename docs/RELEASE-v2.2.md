# v2.2 · 悬浮窗滑出重构：弹出不再闪灰边

---

## 这是什么

**时间规划表 · 电脑版**：课表和作息排在同一条时间轴上的桌面课程表。

它不只知道你几点有课，还知道你几点该起床、几点吃饭、几点睡觉 ——
一天 24 小时从床到床排成一条线，上课、自习、吃饭、运动互相挤时间，
排在一起才看得出一天还剩多少空。

桌面上有一块**悬浮窗小卡片**，随时显示此刻该做什么、还剩多久；
每节课开始前还会**提前提醒**。

**完全离线**：不联网、不上传任何数据，课表只存在本机
（`%APPDATA%\Timetable`），和手机版共用同一套数据格式。

---

## 下载与安装

下载本页附件 `时间规划表-安装程序-2.2.exe`（19.4 MB），支持 **Windows 10 1803+ / Windows 11**。

1. 双击安装。装给**当前用户**，不需要管理员权限，全程不弹 UAC
2. 默认装到 `%LOCALAPPDATA%\Programs\时间规划表`，可以换目录
3. 首次打开会让你选：**用内置示例课表** 还是 **从空白开始**

> 系统没有 WebView2 运行时的话（较新的 Win10 / Win11 都自带），
> 界面会白屏 —— 装一下 [Edge WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/) 即可。
>
> **已经在用旧版本的话，直接覆盖安装**：课表数据存在用户目录，升级、卸载都不会动它。

## 本版内容

### 重构：悬浮窗贴边收起改为「整窗滑出」

收起/展开的实现在底层换了一套，解决的是一个用户实际撞到的问题：

**旧版**：收缩态弹出时，窗口逐帧变大，新露出来的区域来不及重绘，
**弹出中途边缘会闪过一条和主题不同的灰色**。

**新版**：窗口尺寸从此**恒定不变**，收起 = 整窗平移到屏幕外只留一条小把手，
展开 = 整窗平移回来。窗口里每个像素从一开始就画好了，
平移不会产生"还没画出来的区域" —— **那条灰从根上消失了**。

交互上有三处变化：

| 交互 | 旧版 | 新版 |
|---|---|---|
| 贴边停靠 | 四个边都可以 | **只支持左、右两边**（上下边不再吸附，拖过去就是自由浮动） |
| 收起后的样子 | 26×76 的小方块 | 一条 13px 宽的**细把手**（带方向箭头），其余全在屏幕外 |
| 悬停弹出 | 整张卡片滑出 | 滑到**内容贴住屏幕边缘**为止，把手区不占屏幕 |

- 悬停把手滑出、移开自动缩回、单击把手拉出、拖动吸附 —— 手感不变
- 旧版本存的「贴上/下边」状态升级后自动变回自由浮动，拖到左右边重新贴上即可

### 换新图标

应用图标全面换新（青色圆角底 + 蓝色时钟），覆盖四个出现位置：

- exe 文件图标 / 任务栏 / Alt+Tab
- 窗口标题栏（左上角）
- 系统托盘
- 主界面左上角的品牌位（原来是"时"字方块）

### 新增：自定义外观 —— 主色调、背景图、卡片透明度

外观不再只有深浅两档。设置 → 外观里新增三样，**全部即时生效**（不用重启）：

- **主色调**：六个快捷色板 + 自定义取色器。按钮、进度条、「此刻」高亮、
  悬浮窗的剩余时间都会跟着换。挑太浅或太深的颜色会自动做对比度钳制，
  保证在浅色 / 深色两档下都看得清。
- **背景图片**：选一张本机图片铺在主窗口底下。图片会自动压缩到长边 2560
  再存进数据目录（`%APPDATA%\Timetable\background.jpg`），不联网、不上传。
- **卡片不透明度**（30–100%）+ **背景暗化**（0–80%）：把卡片调透明，
  背景图从卡片后面透出来；文字看不清就加大暗化。

> 首次设置背景图时，卡片不透明度会自动从 100% 让到 90% ——
> 否则图被卡片挡得严严实实，第一眼看不出设置成功了。

主题三档（跟随系统 / 始终浅色 / 始终深色）保持不变，仍需重启生效
（小窗口的窗口底色只能在创建时定）。背景图和透明度只在主窗口生效 ——
悬浮窗的底色改不了，透明卡片会在圆角处露出一圈实色，所以它只跟主色调。

### 改进：重复启动拦截

程序已经在运行时（包括收在托盘里的情况），再次双击 exe 会**弹窗提示并退出**，
不会再冒出第二个实例：

- 弹窗会提示去托盘找正在运行的程序
- 用系统级命名互斥体判定，程序崩溃、被强杀都不会留下"假占用"，
  不存在"上次没退干净所以这次起不来"的问题
- 多用户各自登录（快速用户切换 / 远程桌面）互不影响，每人可以各跑一份

### 修复

- 弹出过程中边缘闪灰色（根因见上，整个问题类别已消除）
- 左/右侧任务栏时收起态卡片压在任务栏上的隐患（滑出以显示器边界为基准）
- **浅色主题下标题栏发黑**：pywebview 会按**系统**主题反复改写标题栏深浅
  （窗口构造时 + 每次系统设置变动），系统深色 + 应用浅色时标题栏被它
  抹成黑色。现在把它的判定改成按**应用**主题回答，浅色永远是浅色、
  深色永远是深色。顺带修了一个连带问题：悬浮窗关闭时，标题栏配色和
  提示条样式整段不会执行（它们原来挂在悬浮窗的初始化线程里）。
- **浅色主题下悬浮窗是深色的**：悬浮窗页面的强制主题在一次竞态中静默
  落空（推送跑得比页面加载早），之后就跟着系统走了。现在页面每次加载
  完成都会按设置补推一次主题（悬浮窗、提示条同样覆盖）。

## 功能一览

| 功能 | 说明 |
|---|---|
| 桌面悬浮窗 | 常驻小卡片：此刻在做什么、还剩多久、下一项是什么；可拖动、可贴边（左右）滑出 |
| 课前提醒 | 每节课开始前 5–30 分钟弹提示条 + 响一声 |
| 今天页 | 此刻 / 明天预告（含起床时间）/ 今日时间线 |
| 周课表 | 周一到周日课程网格，可翻周 |
| 课程编辑 | 图形化增删改课程，支持停用单门课 |
| 作息编辑 | 图形化改作息模板、一键改起床时间 |
| 导入导出 | 和手机版互导；AI 提示词生成课表 |
| 日型系统 | 有早八 / 无早八 / 周末分别用不同作息，可裁剪；无课日自动休息 |
| 自定义外观 | 主色调（色板 + 取色器）、主窗口背景图、卡片不透明度与背景暗化，即时生效 |

## 已知限制

- **贴边只支持左右两边**：上下边不再吸附。把手在卡片左右两侧，滑出机制天生是横向的。
- 把手宽 13px，是刻意收窄的「知道在那儿就行」的设计；要拉出也可以单击它。
- 悬浮窗仍只支持主显示器；换主题（浅色 / 深色）需要重启程序才生效。
- 背景图和卡片透明度只在主窗口生效；悬浮窗只跟随主色调。
- 「跟随系统」档下，系统中途切换深浅时，自定义外观的覆盖色不会跟着重算
  （和主题档一样，整套换装重启后必然一致）。
