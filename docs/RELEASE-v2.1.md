# v2.1 · 假期自动识别：没课的日子按休息日过

---

## 这是什么

**时间规划表 · 电脑版**：课表和作息排在同一条时间轴上的桌面课程表。

它不只知道你几点有课，还知道你几点该起床、几点吃饭、几点睡觉 ——
一天 24 小时从床到床排成一条线，上课、自习、吃饭、运动互相挤时间，
排在一起才看得出一天还剩多少空。

桌面上有一块**悬浮窗小卡片**，随时显示此刻该做什么、还剩多久；
每节课开始前还会**提前提醒**。

**完全离线**：不联网、不上传任何数据，课表只存在本机
（`%APPDATA%\Timetable`），和手机版共用同一套数据格式。

---

## 下载与安装

下载本页附件 `时间规划表-安装程序-2.1.exe`（14.0 MB），支持 **Windows 10 1803+ / Windows 11**。

1. 双击安装。装给**当前用户**，不需要管理员权限，全程不弹 UAC
2. 默认装到 `%LOCALAPPDATA%\Programs\时间规划表`，可以换目录
3. 首次打开会让你选：**用内置示例课表** 还是 **从空白开始**

> 系统没有 WebView2 运行时的话（较新的 Win10 / Win11 都自带），
> 界面会白屏 —— 装一下 [Edge WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/) 即可。
>
> **已经在用旧版本的话，直接覆盖安装**：课表数据存在用户目录，升级、卸载都不会动它。

## 本版内容

### 新功能：假期自动识别 —— 没课的日子按休息日过

工作日只要**全天没课**，就自动按休息日处理：

- 睡到 **09:00** 自然醒，全天自由安排
- 有课日模板里的固定安排（晚自习、训练等）**不会**出现
- 今天页、悬浮窗、课表页表头都会显示「无课」

程序不认识校历，但「课表里这天一门课都没有」是数据里的事实 ——
**停课的周次本来就没排课，国庆、中秋等假期会自动变成休息日**，
不需要手动关掉任何东西。

两个边界要知道：

| 情况 | 表现 |
|---|---|
| 假期当天，课表数据里恰好没课 | ✅ 自动识别为休息日 |
| 假期当天，课表数据里还有课 | 按上学日显示 —— 去课程编辑把那门课的周次改掉或停用 |
| 调课补课的周末（周六/周日有课） | 走周末模板，正常显示课程 |

### 新功能：左下角的状态胶囊变成开关

主界面左下角那颗悬浮窗状态胶囊，以前只能看，现在**点一下就切换悬浮窗**：

- 开着显示「悬浮窗运行中」，关着显示「悬浮窗已关闭」
- 和设置页里的开关**双向同步** —— 在哪边切换，另一边都跟着变
- 鼠标悬停会提示「点击开启 / 关闭桌面悬浮窗」

不用再为了开关悬浮窗专门跑一趟设置页。

### 改进：关于页版本号自动显示

「设置 → 关于」里的版本号改为启动时从程序本体读取。
以前它是手写的，程序升到 2.0 的时候界面上还挂着 v1.0 —— 以后不会再脱节。

## 功能一览

| 功能 | 说明 |
|---|---|
| 桌面悬浮窗 | 常驻小卡片：此刻在做什么、还剩多久、下一项是什么；可拖动、可贴边收起 |
| 课前提醒 | 每节课开始前 5–30 分钟弹提示条 + 响一声 |
| 今天页 | 此刻 / 明天预告（含起床时间）/ 今日时间线 |
| 周课表 | 周一到周日课程网格，可翻周 |
| 课程编辑 | 图形化增删改课程，支持停用单门课 |
| 作息编辑 | 图形化改作息模板、一键改起床时间 |
| 导入导出 | 和手机版互导；AI 提示词生成课表 |
| 日型系统 | 有早八 / 无早八 / 周末分别用不同作息，可裁剪；无课日自动休息 |

## 已知限制

- **假期识别跟着课表数据走**：软件不看校历。假期里课表数据仍有课的那几天，
  需要在「课程编辑」里停课或改周次，软件才能识别。
- **「无课日休息」目前只有电脑版有**。同一份课表在手机版上，
  无课的工作日仍会按 B 型作息排（手机版跟进前，两边在无课日会略有差异）。
- 换主题（浅色 / 深色）需要重启程序才生效。
